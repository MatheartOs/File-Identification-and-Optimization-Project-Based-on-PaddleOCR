# 模型的评价及优化

本文从数值结果、抽样对照、误差来源、优缺点和推广方向五个方面评价模型。由于题目未提供逐文件人工标注真值，本文将输出结果中的代表文件、抽样文本、分类概率、复核队列和资源约束表作为检验依据，结合无监督评价指标和风险指标进行综合分析。

## 6.1 误差分析

### 6.1.1 针对于问题1的误差分析

问题一建立历史主题体系，输入为数据集 1 中通过清洗筛选后的 2225 份历史文件。模型采用异构图 PMI 传播、结构业务特征融合和 c-TF-IDF 主题归纳，得到 10 类历史主题。

问题一主要数值结果如下：

| 指标 | 数值 | 含义 |
| --- | ---: | --- |
| 建模文件数 | 2225 | 数据集 1 中进入主题建模的历史文件数 |
| 主题数 | 10 | 历史主题类别数量 |
| 词项数 | 2500 | 中文 2-4 gram 词项数 |
| PMI 词图边数 | 366841 | 正 PMI 共现关系数量 |
| 滑动窗口数 | 404135 | 用于统计词共现的窗口数量 |
| Silhouette | 0.035421 | 聚类类内紧密和类间分离程度 |
| Calinski-Harabasz | 39.333307 | 类间离散度与类内离散度比值 |
| Davies-Bouldin | 3.439216 | 类内散度与类间距离相对比值 |

模型输出的主题分布如下：

| 主题名称 | 样本数量 | 占比 |
| --- | ---: | ---: |
| 资金财政统计类 | 567 | 25.483% |
| 医药项目审批类 | 535 | 24.045% |
| 地区统计指标类 | 375 | 16.854% |
| 制造业产业统计类 | 256 | 11.506% |
| 教育教学管理类 | 174 | 7.820% |
| 生态环境治理类 | 136 | 6.112% |
| 养老服务机构类 | 59 | 2.652% |
| 投资价格统计类 | 49 | 2.202% |
| 项目案件信息类 | 39 | 1.753% |
| 教育基础统计类 | 35 | 1.573% |

从数值上看，轮廓系数较低，说明历史办公文件并非严格球形聚类，不同主题之间存在较强交叉。例如“项目”“资金”“教育”“统计”等词可能同时出现在多个业务材料中。该现象符合题目背景：智能办公文件包含通知、项目、统计表、审批材料和图片 OCR 文本，主题边界天然重叠。因此，问题一不能只用轮廓系数判断优劣，还需要结合代表文件和主题词进行检验。

抽样对照如下：

| 模型主题 | c-TF-IDF 关键词 | 输出代表文件标题或内容线索 | 对照判断 |
| --- | --- | --- | --- |
| 资金财政统计类 | 企业、收入、项目、资金、支出、亿元 | 近三年审计财务报告、财务报表 | 关键词与代表文件均指向资金和财务材料 |
| 制造业产业统计类 | 制造、生产、制造业、工业、金属 | 制造业、工业、生产总值相关统计图片 | 与产业统计主题一致 |
| 教育教学管理类 | 教学、教师、教育、学生、课程 | 本科教学质量报告、教学管理材料 | 与教育教学管理主题一致 |
| 生态环境治理类 | 环境、污染、生态、水资源、水质 | 环境、水质、污染治理相关材料 | 与生态环境治理主题一致 |
| 养老服务机构类 | 老年、养老、公寓、社区 | 老年公寓、养老服务机构材料 | 与养老服务主题一致 |

问题一误差主要来自四方面：

1. OCR 误差：图片统计表虽然 OCR 平均质量较高，但表格数字、单位、页眉页脚仍可能引入噪声。
2. 主题交叉：项目、资金、通知等办公高频词跨主题出现，导致部分样本在聚类边界附近。
3. 无监督建模缺少人工标签：模型输出的是归纳主题而非监督分类，主题名称需要结合代表文件人工润色。
4. 类别粒度限制：10 类主题是论文级别的上层体系，部分大类如资金财政统计类、医药项目审批类内部仍可继续二级拆分。

理论上，若记第 `i` 个历史文件到所属簇中心距离为 `a_i`，到最近其他簇中心距离为 `b_i`，则轮廓系数

```text
s_i = (b_i - a_i) / max(a_i, b_i)
```

可作为该文件主题不确定性的近似度量。当 `s_i` 接近 0 或小于 0 时，说明样本处在多个主题边界上，误分风险较高。总体 `Silhouette=0.035421` 表明模型能够形成可解释主题，但边界样本比例不可忽略。因此，本文在问题二、问题三中继续使用概率、熵和复核机制对问题一的主题边界误差进行补偿。

问题二的误差可由类别概率分布近似估计。对单个样本，若最高类别概率为 `p_{i1}`，可用

```text
E_i^{prob} = 1 - p_{i1}
```

作为保守错分概率上界的近似；若主次类别相对边际差

```text
m_i = (p_{i1} - p_{i2}) / p_{i1}
```

较小，则说明第一、第二类别竞争明显。本文进一步用 `ARS` 和归一化熵 `H_i` 综合判断误差风险。数据集 2 的平均熵为 0.912906，高于数据集 3 的 0.771414，说明数据集 2 的误差风险主要来自概率分散；数据集 3 的平均主类概率为 0.386241，高于数据集 2 的 0.233601，说明其整体分类置信度更高。

因此，问题二并未把低置信样本强行作为高可靠结果，而是将 367 条多类别重叠样本和 102 条未知专家研判样本留给问题三处理，从机制上降低最终归档误差。

问题三误差主要来自权重设定和时间估计。AHP 主观权重体现题意偏好，熵权体现数据分布，但不同单位在真实业务中对时效、风险和成本的偏好可能不同。复核时间 `t_i` 由文本长度和风险状态估计，实际人工处理时长会受人员经验、业务熟悉度和材料复杂度影响。

理论上，若第 `i` 个文件未复核，则其残余风险可表示为

```text
Loss_i = P_i * C_i
```

其中 `P_i` 为综合优先级或错分风险近似，`C_i` 为误归档成本系数。场景 `s` 的未复核风险为

```text
Loss_s = sum_{i: delta_i=0} Loss_i
```

资源增加时，优先队列按 `P_i/t_i` 选择高单位价值样本，因此理论上 `Loss_s` 应单调下降。实际结果中 S1、S2、S3 的未复核风险依次下降，验证了资源优化方向的合理性。

## 6.2 模型的优点

1. 较好地解决了多源异构文件统一建模问题。模型将 Word、PDF、Excel、图片、TXT 和半结构化记录转换为统一文件画像，使后续分类、迁移和复核调度可以在同一数据结构上进行。

2. 建模方法具有一定创新性。问题一采用文档-词 TF-IDF 与词-词正 PMI 构建异构图，并用两跳词图传播近似 GCN 聚合，在不依赖深度学习框架的情况下引入了图语义信息。

3. 分类体系具有可解释性。模型不仅输出类别编号，还输出 c-TF-IDF 主题词、代表文件、业务画像和主题解释，便于论文展示和人工核验。

4. 问题二避免了强行归类。对于多类别重叠和未知样本，模型输出复核状态，而不是简单给出硬标签，使结果更合理，避免低置信样本自动归档带来的较大误差。

5. 评价指标较完整。模型同时计算主类概率、ARS、MII、熵和 TAI，分别衡量归属合理性、可解释性、不确定性和迁移适用性，使问题二的结果描述比较清晰。

6. 问题三兼顾准确性、时效性和经济成本。通过紧急程度、错分风险、复核必要性三个维度建模，并结合 AHP-熵权融合权重，使复核优先级不是单一由置信度决定。

7. 资源约束处理效果较好。S1、S2、S3 三种场景下人工资源利用率均接近 100%，且均优先覆盖未知专家研判样本，说明模型能够在有限资源下得到较满意的复核队列。

8. 模型链路闭合。问题一输出主题体系，问题二完成迁移归属，问题三进行风险分级和资源调度，三问之间逻辑连贯。

## 6.3 模型的缺点

1. 无监督主题体系仍存在一定主观性。问题一缺少官方人工标签，主题数 `K=10` 和主题名称需要结合业务理解确定，具有一定人工解释成分。

2. 模型建立在数据集 1 能代表历史主题体系的前提下。若后续新流入数据出现大量历史中不存在的新业务主题，当前模型只能识别为未知样本，不能自动生成全新类别。

3. OCR 和文本清洗误差会影响模型效果。图片表格、扫描 PDF、低质量文本和元数据文件可能造成主题词缺失或噪声增加。

4. 部分指标为近似构造。MII 使用主题词贡献集中度近似模型可解释性，TAI 使用数据集级 MMD 衡量迁移适用性，不能完全替代真实人工评审。

5. 权重设置有一定局限性。AHP 主观权重、特殊关注增强系数和复核时间估计均基于题意和经验设定，在不同办公单位或不同业务规则下可能需要重新校准。

6. 问题三中的资源调度采用优先队列近似优化，没有进一步引入整数规划或多目标全局搜索，因此在极端资源约束下可能不是严格全局最优。

7. 当前模型对长表格、跨页扫描 PDF 和复杂版式文件的处理仍有改进空间，尤其是扫描 PDF 转图片 OCR 尚未完全纳入自动链路。

## 6.4 模型的推广

1. 引入人工标注闭环。可抽取高置信、边界和未知样本进行人工标注，用标注结果反向校准主题数、分类阈值、ARS 权重和复核规则，形成主动学习闭环。

2. 对大类进行二级主题拆分。资金财政统计类、医药项目审批类等样本量较大，可在其内部继续建立子主题模型，使归档目录更细致。

3. 引入预训练语言模型。若计算环境允许，可使用中文 BERT、SimCSE 或 Sentence-BERT 替换或融合字符级 TF-IDF 表示，提高短文本和语义改写场景下的分类能力。

4. 使用真实 GCN 或图神经网络。当前两跳 PMI 传播是轻量近似方案，后续可在有标注样本后训练文本-单词异构图 GCN，进一步增强图结构表示能力。

5. 优化 OCR 与版面理解。可对扫描 PDF 增加 PDF 转图片 OCR，对表格文件增加单元格结构恢复，对长图增加版面分块识别，从源头降低文本抽取误差。

6. 建立动态主题更新机制。当未知专家研判样本累计到一定数量时，可自动触发新主题发现，将新类纳入历史主题体系，适应办公业务变化。

7. 拓展资源调度模型。问题三可进一步引入整数规划、遗传算法或强化学习，根据人员专业、任务截止时间、复核成本和误归档损失进行多目标优化。

8. 结合业务系统部署。模型可推广到智能办公平台中的自动归档、风险预警、复核派单和知识库维护模块，实现“自动处理大多数文件、人工处理关键文件”的人机协同治理流程。
