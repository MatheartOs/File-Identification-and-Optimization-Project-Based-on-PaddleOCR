# 问题二求解

## 5.2 问题2的模型建立与求解

问题二承接问题一建立的历史文件主题体系，目标是在不重新构造类别的前提下，将数据集 2 和数据集 3 中的新流入文件归入已有类别，并对分类效果、合理性、可解释性和迁移适用性进行评价。同时，对于多类别重叠样本和无法明确归类样本，需要建立识别规则并给出后续处理思路。

本文将问题二建模为“源域主题空间到目标域文件的迁移分类与评价问题”。其中，数据集 1 为源域，数据集 2、数据集 3 为目标域；问题一得到的 10 类历史主题作为固定分类体系。模型不是简单地对新文件输出单一标签，而是同时输出类别概率、主次类别差异、解释词、迁移适用性和自动归档/人工复核状态。

### 5.2.1 模型的建立

我们需要解决的问题是：在历史文件主题体系已经建立的条件下，判断新流入的半结构化记录和匿名原始文件分别属于哪一类历史主题，并判断该归属是否可靠。题目要求不仅要完成分类，还要自主设计指标评价分类效果、合理性、可解释性和迁移适用性；对于多类别重叠或无法明确归类的样本，还需建立识别模型并给出处理思路。

在建模前，本文剔除以下不适合直接迁移分类的数据：

1. 图片侧车元数据：仅包含图片名称、编号或下载地址，不能代表文件主题。
2. 仅元数据样本：正文缺失，无法形成有效语义表示。
3. 扫描 PDF 待 OCR 样本：文本尚未稳定抽取。
4. 有效中文语义过短样本：无法支撑主题判断。
5. 解析质量低于迁移阈值的样本：清洗结果不足以支持自动归档。

剔除或转入专家研判后，本文采用“异构图主题空间复用 + 距离概率化分类 + 语义锚定校准 + 综合评价指标”的迁移分类模型。该模型的优点在于：

1. 继承问题一主题体系，保证三问类别口径一致。
2. 复用源域 TF-IDF、PMI 词图和主题中心，避免对目标域重新聚类导致类别漂移。
3. 同时融合文本、结构、质量和业务特征，适合多源异构办公文件。
4. 通过概率、熵、ARS、MII、TAI 等指标评价分类可靠性，避免低置信样本被强行归档。
5. 能显式识别多类别重叠样本和未知样本，为问题三人工复核优先级排序提供输入。

具体模型建立步骤如下。

步骤 1：构造源域与目标域建模文本。

将每个文件的标题、正文、OCR 文本和业务关键词合并为统一文本：

```text
d_i = Clean(title_i, clean_text_i, business_keywords_i)
```

其中 `title_i`、`clean_text_i`、`business_keywords_i` 分别表示第 `i` 个文件的标题字段、清洗正文和业务关键词字段；`Clean(·)` 表示中文语义过滤函数，主要去除英文编码、URL、模板词和大量数字噪声，同时保留业务关键词。

步骤 2：复用问题一的源域主题空间。

在数据集 1 的历史文件上构造字符级 2-4 gram TF-IDF 文档-词矩阵：

```text
X ∈ \mathbb{R}^{N × M}
```

其中 `\mathbb{R}` 表示实数域。

并基于滑动窗口统计词语共现，计算正 PMI 词图：

```text
PMI(t,s)=log(n_W(t,s)N_W/(n_W(t)n_W(s)))
```

仅保留正 PMI 并按行归一化，得到词图传播矩阵 `\hat{W}`。

步骤 3：进行两跳图传播。

为增强短文本和同义近义词的语义表达，对文档-词矩阵进行两跳传播：

```text
X_{\mathrm{graph}} = X + 0.60 X\hat{W} + 0.30 X\hat{W}^2
```

其中第一项保留原始关键词，一跳传播引入直接共现词，二跳传播引入间接相关词。该过程可视为轻量 GCN 聚合近似。

步骤 4：融合结构特征与业务特征。

模型进一步引入页数、段落数、表格数、图片数、标题数、解析质量、OCR 置信度、文本长度、文件大小以及通知、会议、项目、资金、合同、人事、截止、紧急等业务标签，形成融合特征：

```text
F = [X_{\mathrm{graph}}, S, C]
```

该融合方式同时保留图增强文本信息、结构质量信息和业务锚点信息。

步骤 5：构造共享低维迁移空间。

在源域上拟合 TruncatedSVD，将源域与目标域同时投影到 80 维共享空间：

```text
z_i = SVD(\tilde{F}_i)
```

其中 `SVD(·)` 表示截断奇异值分解降维方法。随后在源域上拟合 KMeans，得到 10 个历史主题中心 `c_1,c_2,...,c_K`。

步骤 6：距离概率化分类。

对目标文件 `i`，计算其嵌入向量 `z_i` 到各主题中心的距离：

```text
d_{ik}=||z_i-c_k||_2
```

其中 `||·||_2` 表示欧氏范数。

并使用温度 softmax 将距离转化为类别概率：

```text
p_{ik}=exp(-d_{ik}/\tau)/sum_{r=1}^{K} exp(-d_{ir}/\tau)
```

其中 `r` 为类别求和索引。

预测主题为：

```text
y_i=argmax_{k} p_{ik}
```

其中 `argmax` 表示取使类别概率最大的主题编号。

步骤 7：语义锚定概率校准。

为避免“服务、中心、项目、管理”等泛词造成短文本吸附，模型对每个主题加入业务锚词校准。例如教育教学类锚词包括“教学、教师、学生、课程、教育、学院”，生态环境类锚词包括“生态、环境、污染、水质、绿色、排放”。最终类别概率由距离概率和锚词概率加权得到：

```text
\mathbf{p}_i = (1 - \beta)\mathbf{p}_i^{dist} + \beta\mathbf{p}_i^{lex}
```

当前取 `\beta=0.45`。

步骤 8：建立评价指标。

归属合理性指标 ARS 定义为：

```text
ARS_i = \alpha p_{i1} + (1-\alpha)(p_{i1}-p_{i2})/p_{i1}
```

当前取 `\alpha=0.60`。ARS 越高，说明主类置信度越高、主次类差距越明显。

类别概率熵定义为：

```text
H_i = -sum_{k=1}^{K} p_{ik} log_2(p_{ik}) / log_2(K)
```

熵越高，说明类别分布越分散，样本越可能处于边界或分布外。

可解释性指标 MII 由预测主题代表词在目标文本中的贡献集中度计算：

```text
MII_i = 1 - (-sum_{j=1}^{L_e} a_j log_2 a_j)/log_2(L_e)
```

MII 越高，说明少数解释词即可支撑分类结论。

迁移适用性指标 TAI 由源域和目标域嵌入分布的 MMD 转换得到：

```text
TAI_d = exp(-MMD^2(Z_s,Z_t^{(d)}))
```

其中 `Z_t^{(d)}` 表示数据集 `d` 对应的目标域样本嵌入集合。TAI 越接近 1，说明目标域与历史源域越接近，迁移分类越适用。

步骤 9：建立边界样本识别规则。

模型将目标样本划分为四类：

| 状态 | 含义 | 处理方式 |
| --- | --- | --- |
| `A_clear_auto_archive` | 主类概率较高、解释较充分 | 清晰自动归档 |
| `A_assisted_archive` | 可归档但建议保留解释或抽检 | 辅助归档 |
| `B_overlap_manual_review` | 主次类概率接近 | 多类别重叠复核 |
| `C_unknown_expert_review` | 概率过低、熵过高或文本不足 | 未知专家研判 |

针对题目要求的三个核心问题，结果综述如下。

第一，将新数据归入相应类别。模型将数据集 2 和数据集 3 全部新流入记录纳入统一处理，其中 4419 条形成稳定分类结果。数据集 2 主要归入教育教学管理类，数据集 3 主要归入教育教学管理类、医药项目审批类、生态环境治理类、资金财政统计类和项目案件信息类。

第二，评价分类效果、合理性、可解释性和迁移适用性。本文用主类概率评价分类置信度，用 ARS 评价归属合理性，用 MII 评价解释词集中度，用 TAI 评价目标域到源域的迁移适用性。结果显示，数据集 3 的 TAI 为 0.699263，高于数据集 2 的 0.588393；数据集 3 的平均 ARS 为 0.418351，高于数据集 2 的 0.240491，说明数据集 3 在当前模型空间中的迁移适用性和分类稳定性更好。

第三，识别多类别重叠样本和无法明确归类样本。模型共识别出 367 条多类别重叠复核样本和 102 条未知专家研判样本。其中，数据集 2 有 134 条重叠复核样本和 80 条未知专家研判样本；数据集 3 有 233 条重叠复核样本和 22 条未知专家研判样本。这些样本不直接自动归档，而是作为问题三人工复核优先级模型的重要输入。

综合来看，问题二模型实现了从历史主题体系到新流入数据的迁移分类，并通过概率、解释、分布差异和状态判别形成了可解释的评价体系。该结果既完成了题目对新数据归属判断的要求，也为后续复核必要性评估和资源约束优化提供了可靠的数据基础。
