# 问题三求解

## 5.3 问题3的模型建立与求解

问题三在问题二迁移分类结果基础上，进一步解决“哪些文件需要人工复核、复核优先顺序如何安排、不同资源约束下如何调度”的问题。题目要求从紧急程度、错分风险、复核必要性三个方面进行等级划分，重点关注主题不明确文件、高时效文件和资金分配相关文件，并在数据集 4 给出的 S1、S2、S3 三种资源约束下比较处理结果。

本文将问题三建模为“风险分层与资源约束下的人工复核优先级优化问题”。模型承接问题二输出的类别概率、归属合理性、解释性指数、迁移适用性、边界状态和未知状态，先构建三维风险评分，再用 AHP-熵权融合得到综合优先级，最后在人工工时和复核数量约束下形成复核队列与自动归档队列。

### 5.3.1 模型的建立

我们需要解决的问题是：在自动分类已经完成但仍存在错分风险的条件下，判断新流入文件是否需要人工复核，并在有限人工资源下优先处理最值得复核的文件。题目要求同时考虑归档准确性、时效性和经济成本，因此不能只按模型置信度排序，也不能将所有边界样本全部交给人工处理。

建模前，本文使用问题二输出的 4519 条新流入记录作为待处理对象。对于已判为清晰自动归档的文件，主要考虑自动归档可靠性；对于多类别重叠、未知专家研判、高时效和资金相关文件，重点考虑人工复核必要性。模型不再重新分类，而是将问题二结果转化为风险评分和调度决策。

本文采用“熵权-AHP 融合 + 特殊关注增强 + 资源约束优先队列”的 RTF-RPO 模型。该模型的优点在于：

1. 同时考虑紧急程度、错分风险和复核必要性，符合题目三维分级要求。
2. 将题目明确要求关注的主题不明确、高时效、资金相关文件纳入特殊增强机制。
3. 使用 AHP 体现业务偏好，使用熵权体现数据差异，避免权重完全主观。
4. 在 S1、S2、S3 三种资源约束下输出不同复核队列，便于比较不同资源配置效果。
5. 同时输出人工复核、专家研判、重点抽检、自动归档和辅助归档五类动作，便于形成完整治理方案。

具体模型建立步骤如下。

步骤 1：构建紧急程度得分。

紧急程度由时效信号、资金信号和项目属性共同决定。文本中若出现“截止、限期、反馈、整改、会议、考试、紧急、公示”等词，或清洗阶段识别到截止时间、紧急标记，则时效信号升高。紧急程度得分定义为：

```text
U_i = 0.62\Theta_i + 0.18\Phi_i + 0.20G_i
```

所有分量均归一化到 `[0,1]`，分数越高表示越需要优先处理。

步骤 2：构建错分风险得分。

错分风险主要来自问题二的分类不确定性。若最高类别概率低、类别概率熵高、主次类差距小、迁移适用性低或解析质量差，则错分风险较高：

```text
m_i = (p_{i1} - p_{i2}) / max(p_{i1}, \varepsilon)
```

```text
R_i = 0.30(1 - p_{i1})
    + 0.26H_i
    + 0.22(1 - m_i)
    + 0.12(1 - TAI_i)
    + 0.10(1 - Q_i)
```

其中 `max(·)` 表示取较大值。该设计使低概率、高熵、低边际差和低质量样本得到更高风险分。

步骤 3：构建复核必要性得分。

复核必要性不仅与错分风险有关，还与问题二状态和解释充分程度有关。模型先将问题二状态映射为基础复核强度：

| 问题二状态 | 基础复核强度 |
| --- | ---: |
| 清晰自动归档 | 0.08 |
| 辅助归档/抽检 | 0.30 |
| 多类别重叠复核 | 0.82 |
| 未知专家研判 | 0.92 |

再结合错分风险、解释不足、资金信号和时效信号计算复核必要性：

```text
N_i = 0.36S_i
    + 0.24R_i
    + 0.16(1 - MII_i)
    + 0.14\Phi_i
    + 0.10\Theta_i
```

该公式保证未知样本和多类别重叠样本优先获得较高复核必要性。

步骤 4：采用 AHP-熵权融合确定综合权重。

三个评价维度分别为：

```text
V_{i1}=U_i, V_{i2}=R_i, V_{i3}=N_i
```

主观权重根据题意设置为：

| 维度 | 主观权重 |
| --- | ---: |
| 紧急程度 | 0.34 |
| 错分风险 | 0.38 |
| 复核必要性 | 0.28 |

客观熵权计算为：

```text
z_{ij} = V_{ij} / \sum_{i=1}^{N} V_{ij}
```

```text
e_j = - (1 / \ln N) \sum_{i=1}^{N} z_{ij}\ln z_{ij}
```

```text
w_j^o = (1 - e_j) / \sum_{r=1}^{3}(1 - e_r)
```

其中 `\ln` 表示自然对数，`r` 为评价维度求和索引。最终采用主客观融合权重：

```text
w_j = (1-\lambda)w_j^s + \lambda w_j^o
```

当前取 `\lambda=0.35`。

步骤 5：特殊关注增强。

题目明确要求重点关注主题不明确文件、高时效文件和资金分配相关文件，因此设置特殊关注指示变量 `I_i`。基础综合优先级为：

```text
P_i^0 = w_1U_i + w_2R_i + w_3N_i
```

特殊关注增强后：

```text
P_i = P_i^0(1+\mu I_i)
```

当前取 `\mu=0.18`。该设置使主题不明确、高时效和资金相关文件在同等风险条件下获得更高处理优先级。

步骤 6：高中低等级划分。

对紧急程度、错分风险、复核必要性和综合优先级分别使用分位数规则划分高中低等级：

```text
Level(x_i) =
高, x_i >= Q_{70}
中, Q_{30} <= x_i < Q_{70}
低, x_i < Q_{30}
```

该规则适合无人工标签条件下的相对风险分层，可保证复核资源优先流向排名靠前的文件。

步骤 7：建立建议动作规则。

根据问题二状态、综合优先级和业务风险，将文件划分为五类动作：

| 动作编码 | 中文含义 | 处理逻辑 |
| --- | --- | --- |
| `expert_review` | 专家研判 | 未知主题或不可明确归类样本 |
| `manual_review` | 人工复核 | 多类别重叠样本 |
| `priority_sampling` | 重点抽检 | 高优先级、资金相关或高时效样本 |
| `auto_archive` | 自动归档 | 清晰且可靠的样本 |
| `assisted_archive` | 辅助归档 | 可归档但需保留解释或后续抽检 |

动作编码为输出表中的文本标记，用于连接模型计算结果和实际治理流程。

步骤 8：建立资源约束优化模型。

在资源场景 `s` 下，复核队列需满足：

```text
\sum_i t_i\delta_i <= L_s
```

```text
\sum_i \delta_i <= K_s
```

复核队列按照三层优先规则排序：

1. 未知专家研判样本优先；
2. 多类别重叠复核样本其次；
3. 高时效、资金相关或高综合优先级抽检样本再次。

同一层内按综合等级、综合优先级和单位时间治理价值排序。单位时间治理价值采用 `P_i/t_i` 衡量。

自动归档可靠性得分为：

```text
A_i^{arch} = 0.45p_{i1} + 0.35ARS_i + 0.20MII_i
```

该得分用于在自动归档能力有限时优先归档更可靠的文件。

针对题目要求的三个核心问题，结果综述如下。

第一，从紧急程度、错分风险和复核必要性三个方面进行等级划分。模型将 1622 条记录划为高紧急程度，将 1356 条记录划为高错分风险，将 1356 条记录划为高复核必要性，同时给出综合优先级等级，为后续复核排序提供了统一依据。

第二，判断是否需要人工复核及复核优先顺序。模型将未知专家研判样本、多类别重叠样本和重点抽检样本纳入需要复核或抽检范围，并通过 `P_i` 和 `P_i/t_i` 确定同类样本内部优先顺序。三种场景均优先覆盖 102 个未知专家研判样本，说明主题不明确文件被放在最高处理优先级。

第三，在资源约束场景下比较处理结果并提出建议。S1 资源最紧，复核 137 条记录，主要覆盖未知样本和少量重叠样本；S2 增加工时后复核数提升到 173，重叠样本覆盖数增加到 71；S3 资源最充足，复核 210 条记录，重叠样本覆盖数增加到 108，未复核风险降至 1236.019877。若实际办公场景更强调成本控制，可采用 S1；若强调风险控制和归档准确性，建议采用 S3；若需要在成本和风险之间折中，S2 是较均衡的选择。

综合来看，问题三模型在问题二分类结果基础上建立了可解释的风险分层与资源调度机制，既能给出每个文件是否复核的判断，也能在不同资源约束下输出复核优先队列。该结果较好地实现了归档准确性、时效性和经济成本之间的平衡。
